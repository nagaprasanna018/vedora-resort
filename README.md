# Vedora Resort

A premium, frontend-only luxury resort booking experience built with Next.js.

## What this first version includes

- Cinematic dusky resort visual direction
- Responsive luxury landing page
- Mock availability and booking interaction
- Guest selector and date inputs
- Room / suite cards with pricing
- Experiences section
- Brand story section
- Animated interactions with Framer Motion
- Vercel-ready Next.js structure

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Next build steps

## Deployment

The project is designed for Vercel. Connect the GitHub repository to Vercel and deploy with the default Next.js settings.
